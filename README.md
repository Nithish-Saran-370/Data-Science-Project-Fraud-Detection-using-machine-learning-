# Data-Science-Project-Fraud-Detection-using-machine-learning-
Used kaggle fraud detection dataset, link:https://www.kaggle.com/datasets/amanalisiddiqui/fraud-detection-dataset?resource=download
Imported the dataset then did data wrangling
Exploratory data analysis was done to find key insights and visualisation about the data.
Then use feature selection and model training to train the ML model to detect fradulent transcation.
Streamlit was used to build interactive application for teams to use.
